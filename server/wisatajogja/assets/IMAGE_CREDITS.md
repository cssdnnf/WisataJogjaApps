# Kredit Aset Gambar

Gambar destinasi diunduh dari Wikimedia Commons untuk kebutuhan prototipe pembelajaran.
Atribusi utama:

- Pantai Timang: *Gondala pantai Timang - Gunung Kidul, DIY.jpg*
- Pantai Parangtritis, Gunung Merapi, Candi Prambanan, Malioboro, Goa Jomblang,
  HeHa Sky View, Taman Sari, Pantai Drini, dan Kalibiru: berkas Wikimedia Commons
  hasil pencarian nama destinasi terkait.
- Foto profil demo: Unsplash (`photo-1494790108377-be9c29b29330` dan
  `photo-1500648767791-00dcc994a43e`).
- Peta statis: ubin peta © OpenStreetMap contributors, tersedia di bawah ODL 1.0.
  Atribusi dicetak pada setiap gambar peta.

Lisensi tiap berkas Wikimedia Commons dapat berbeda. Untuk publikasi komersial,
periksa kembali halaman berkas asal dan cantumkan atribusi sesuai lisensinya.
